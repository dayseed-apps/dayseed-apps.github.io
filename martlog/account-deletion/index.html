계정 및 데이터 삭제

MartLog (마트로그) · Dayseed

MartLog 계정과 계정에 연결된 기록·사진은 앱에서 삭제를 요청하거나 이메일로 요청할 수 있습니다. 앱을 설치하지 않았거나 로그인할 수 없는 경우에도 아래 방법을 이용할 수 있습니다.

웹에서 삭제 요청하기

이메일로 계정 삭제 요청

받는 사람: dayseed.help@gmail.com

제목에 “마트로그 계정 삭제 요청”을 적고 로그인에 사용한 이메일 주소와 로그인 방식(Google·Apple)을 알려주세요. Apple의 이메일 가리기를 이용했다면 비공개 이메일 주소를 알고 있는 범위에서 알려주세요.

비밀번호, 인증 코드, 로그인 토큰은 보내지 마세요. 이메일 접근을 잃었거나 해킹이 의심되면 해당 상황을 함께 알려주세요.

계정 소유 여부 확인을 위해 추가 확인을 요청할 수 있습니다. 이메일을 보냈다는 사실만으로 계정을 삭제하지 않으며, 소유권을 확인하기 어려우면 처리를 보류하고 확인 방법을 안내합니다. 확인이 완료되면 합리적인 기간 내에 처리하고 결과를 안내합니다.

앱에서 직접 삭제하기

  1. MartLog 앱에서 삭제할 계정으로 로그인합니다.
  2. 「설정 > 계정 관리 > 회원탈퇴」를 선택합니다.
  3. Google 또는 Apple 재인증 등 화면 안내에 따라 요청을 완료합니다.

서버 사진과 계정 정리는 비동기로 진행됩니다. 처리 실패 시 재시도하므로 요청 직후 모든 삭제가 완료되는 것은 아닙니다.

삭제되는 데이터

  • 로그인 계정 정보(이메일·이름·계정 식별자 등)
  • 해당 계정의 영수증·상품·장바구니 기록과 백업 사진
  • 가입 안내 메일의 발송 관리 기록과 대기 작업

다른 로그인 계정이나 게스트 기록은 해당 계정 삭제의 대상이 아닙니다. 게스트 기록은 게스트 상태에서 「설정 > 모든 데이터 삭제」로 삭제할 수 있습니다.

별도 보관·처리되는 정보

삭제 처리와 늦게 도착한 인증 이벤트의 중복 처리를 막기 위해 UID, 인증 계정 생성 시각, 처리 상태·정리 시각을 담은 최소 처리 기록이 남습니다. 진행 중인 작업 정보는 정리 완료까지 유지될 수 있으며, 정리 완료 후 최소 처리 기록은 8일간 보관하고 만료 후 주기 작업으로 삭제합니다.

AI 분석 비용 확인과 운영 분석을 위한 앱 식별값별 사용량 지표는 현재 별도의 자동 만료 기한 없이 보관하며 계정 탈퇴만으로 자동 삭제되지 않습니다. 사용량 문서에는 회원 UID·이름·이메일·영수증 사진·본문·상품명을 저장하지 않지만 같은 앱 식별값의 이력이 연결될 수 있습니다. 가입 안내 메일·문의 내역과 외부 사업자의 진단·운영·백업 정보에는 각 서비스의 보관·제거 절차가 적용됩니다. 관련 권리 요청은 위 이메일로 문의해 주세요.

앱 삭제와 로그아웃만으로 계정의 서버 기록·사진이 삭제되지는 않습니다. 외부 사업자의 처리·보관 안내는 개인정보처리방침을 확인해 주세요.

계정을 유지하면서 기록 삭제하기

로그인한 상태에서 「설정 > 모든 데이터 삭제」를 선택하면 계정 기록·사진을 삭제하고 로그인 계정은 유지합니다.
