개인정보처리방침

MartLog

최종 업데이트: 2026년 10월 18일 · 1.1.0 기능 반영

1. 총칙

Dayseed(이하 “당사”)는 MartLog(이하 “서비스”)에서 처리하는 개인정보의 항목·목적·보유기간·처리 위탁 등을 안내합니다.

MartLog는 로그인 없이도 가격 기록과 장바구니를 이용할 수 있습니다. 게스트 기록은 기기에 저장되며, 로그인하면 계정 기록은 클라우드(Google Firebase)에, 영수증 사진은 클라우드(Cloudflare)에 저장되어 동기화·복원됩니다. AI 영수증 분석을 이용하면 사진 또는 텍스트가 외부 AI 서비스로 전송됩니다. 미구매 장바구니 후보가 있으면 매칭을 위해 후보의 내부 식별자와 품목명도 함께 전송될 수 있습니다.

2. 처리하는 개인정보 항목

로그인 정보: Google·Apple 로그인으로 제공되는 이메일, 이름(제공되는 경우), 계정 식별자와 로그인 제공자 정보는 계정 인증·관리 및 가입 안내에 사용됩니다. Apple의 이메일 가리기를 선택하면 비공개 이메일 주소를 처리합니다.

이용자가 입력하는 기록: 영수증 사진·인식 텍스트, 매장명, 구매일시, 결제 총액, 상품명·수량·가격·할인·용량, 상품 메모·즐겨찾기, 장바구니 항목과 계산 정보 등을 처리합니다. 게스트 기록은 로그인 후 동기화 여부를 선택할 수 있습니다.

가입 안내·문의: 가입 안내 메일의 수신 이메일·로그인 방식·발송 상태, 문의 또는 삭제 요청 시 이용자가 제공한 이메일과 내용을 처리합니다. 비밀번호나 로그인 인증 토큰을 문의 메일로 요청하지 않습니다.

자동으로 처리되는 정보:

  • 앱에서 사용량 구분에 사용하는 값(iOS Keychain의 임의 UUID 또는 Android OS 빌드 ID), 앱 버전, 운영체제·기기 정보 및 외부 인증 서비스가 보안·통신을 위해 처리하는 IP 주소
  • AI 분석 요청 횟수, 토큰 수, 처리 비용·모델·처리 시간 등 사용량 지표
  • 크래시·성능 진단 정보와 화면 이동·영수증 입력·장바구니 사용 등 분석 이벤트
  • Google AdMob이 처리하는 광고 식별자(IDFA/AAID), 기기 정보, IP 주소로 유추한 대략적인 위치와 광고 노출·클릭 정보

광고와 추적 관련 처리는 운영체제 권한 및 광고 동의 설정에 따릅니다. 이 값은 비정상 사용 방지에 이용하며, 단순히 이름이 없다는 이유로 익명 정보라고 간주하지 않습니다. Android OS 빌드 ID는 기기별 고유값이 아니므로 같은 OS 빌드의 기기가 값을 공유하거나 OS 업데이트 후 바뀔 수 있습니다.

3. 처리 목적

  • 계정 인증·관리, 최초 가입 안내 및 이용자 문의 처리
  • AI 영수증 분석, 상품별 가격 기록·비교, 장바구니 기능 제공
  • 계정 기록과 영수증 사진의 동기화·백업·복원
  • 앱 식별값별 사용량 관리, 비정상 사용 차단, 장애·성능 분석
  • 이용 통계 분석 및 무료 서비스 운영을 위한 광고 제공

영수증 사진·본문은 영수증 분석과 이용자의 기록 저장·복원을 위해 처리합니다. 당사가 별도의 품질 개선 자료나 모델 학습 데이터로 이용하지 않습니다. 향후 별도 이용을 도입하면 목적·항목·보관 기간을 안내하고 선택 동의를 요청합니다. 동의하지 않아도 기본 기능을 이용할 수 있습니다.

4. 보유기간과 삭제

기기 기록: 앱에서 해당 기록을 삭제하거나 앱 데이터를 삭제할 때까지 보관됩니다. 게스트 기록을 계정에 동기화하면 서버 반영과 충돌 해결이 확인된 후 게스트 원본을 정리합니다. 기기 기록 삭제를 선택하면 추가 확인 후 게스트 기록과 사진을 삭제합니다.

계정 기록·사진: 이용자가 기록 삭제, 「모든 데이터 삭제」 또는 「회원탈퇴」를 요청할 때까지 보관합니다. 로그인 상태의 모든 데이터 삭제는 계정 기록·사진을 삭제하되 로그인 계정을 유지하며, 회원탈퇴는 로그인 계정도 삭제합니다. 서버 사진은 비동기 정리 작업으로 삭제되어 요청 즉시 모든 삭제가 완료되는 것은 아닙니다. 실패한 정리는 재시도합니다.

계정 삭제 처리 기록: 삭제 처리와 늦게 도착한 인증 이벤트의 중복 처리를 막기 위해 계정 식별자(UID), 인증 계정 생성 시각, 처리 상태와 정리 시각을 최소한으로 보관합니다. 진행 중인 작업 정보는 정리 완료까지 유지될 수 있습니다. 정리 완료 후의 최소 처리 기록은 8일간 보관하고, 만료 후 주기 작업으로 삭제합니다.

가입 안내 발송 기록: 중복 발송 방지·재시도에 사용하며 회원탈퇴 시 삭제합니다. 이미 전송된 메일은 수신자의 메일함과 발신 메일 서비스의 보관 절차에 따릅니다.

사용량 지표: 비용 보호와 악용 방지를 위해 위 앱 식별값을 기준으로 저장되며 계정 탈퇴만으로 자동 삭제되지 않습니다. 보관·삭제 관련 요청은 아래 연락처로 문의할 수 있습니다.

외부 사업자의 처리: 당사가 관리하는 기록의 삭제와 외부 사업자의 운영·백업 데이터 제거는 다를 수 있습니다. Firebase Authentication은 해당 인증 계정의 삭제가 시작된 후 운영·백업 시스템에서 제거하는 데 최대 180일이 걸릴 수 있으며, Crashlytics는 진단 정보와 관련 식별자를 90일 보관 후 제거 절차를 시작합니다. 분석·성능 정보는 각 서비스의 설정과 정책에 따릅니다.

AI 분석 공급자는 API 입력·출력을 원칙적으로 30일 이내 삭제한다고 안내합니다. 안전성 검토 대상 모델, 악용 방지·법적 의무 등에는 예외가 있으므로 공급자의 보관 안내를 확인해 주세요.

서비스처리 위치 및 보관 안내
Firebase Authentication계정 인증정보는 미국에서 처리됩니다. 해당 인증 계정의 삭제가 시작된 후 운영·백업 시스템에서 180일 이내 제거되며, 인증 과정의 IP 로그는 수 주간 보관됩니다.
Firebase 진단·분석 등지역 선택을 제공하지 않는 서비스는 Google의 글로벌 인프라에서 처리될 수 있습니다. Crashlytics는 진단 정보와 관련 식별자를 90일 보관 후 제거 절차를 시작합니다. 다른 서비스는 처리 항목과 서비스 설정·정책에 따릅니다.
Cloudflare R2사진 저장 국가를 특정 국가로 고정해 안내할 수 없습니다. 아시아·태평양(APAC) 위치 힌트는 특정 국가의 저장을 보장하지 않습니다. 당사가 관리하는 사진의 보관·삭제 기준은 제4항과 같습니다.
Anthropic APIAPI 데이터는 미국에 저장되며 미국·유럽·아시아·호주의 일부 국가에서 추론이 처리될 수 있습니다. API 입력·출력은 원칙적으로 30일 이내 삭제되지만 별도 계약·기능·안전정책·법적 의무에 따른 예외가 있습니다.
GmailGoogle의 글로벌 서비스에서 처리될 수 있습니다. 발신·수신 메일 사본은 각 메일함의 삭제 상태와 메일 서비스의 보관·제거 절차에 따릅니다.
Google Analytics·AdMobGoogle의 분산 인프라에서 처리될 수 있습니다. 보관기간은 데이터 종류와 서비스 설정·정책에 따르며, 계정 기록 삭제가 이들 서비스의 모든 운영·진단·광고 정보 삭제를 의미하지는 않습니다.

로그인과 AI 분석은 선택 기능입니다. 로그인 없이 기기에서 기록을 관리하거나 AI 분석 대신 직접 입력할 수 있습니다. 계정의 서버 기록·사진 삭제는 제7항의 방법으로 요청할 수 있습니다. 외부 사업자의 처리 위치·보관 안내와 문의 창구는 아래 공식 문서를 확인해 주세요.

장바구니 후보의 입력 용량은 외부 AI 요청에 보내지 않고 서버에서 분석 결과에 적용합니다. 당사는 현재 API 요청을 모델 학습에 제공하도록 별도 허용하지 않습니다. AI 분석 공급자는 상용 API 입력·출력을 기본적으로 모델 학습에 사용하지 않는다고 안내합니다.

7. 이용자의 권리 및 행사 방법

  • 앱 설정에서 「모든 데이터 삭제」 또는 「회원탈퇴」를 요청할 수 있습니다. 로그인 상태와 게스트 상태의 삭제 범위를 확인해 주세요.
  • 앱에 로그인할 수 없어도 계정 및 데이터 삭제 요청 페이지를 통해 이메일로 요청할 수 있습니다. 소유권 확인 후 처리하며 확인이 어려우면 추가 확인을 요청합니다.
  • 사진 접근 권한은 운영체제 설정에서 회수할 수 있습니다.

앱 삭제나 로그아웃만으로 서버의 계정 기록·사진이 삭제되지는 않습니다. 개인정보의 열람·정정·삭제·처리 정지 등은 아래 이메일로 요청해 주세요.

8. 안전성 확보 조치

계정 인증과 서버 접근 통제, App Check, 암호화된 네트워크 통신을 사용합니다. 사진은 공개 링크로 게시하지 않고 계정 인증 후 제한된 시간 동안 접근 가능한 주소로 제공합니다. 비밀번호·인증 토큰과 서버 키를 문의 메일로 요구하지 않습니다.
